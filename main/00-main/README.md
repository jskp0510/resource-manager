# 통합 테스트본

## 실행 준비

- Java 17 이상이 필요합니다.
- 제공받은 `.env` 파일과 `resource-manager-demo.jar`를 같은 폴더에 둡니다.
- 테스트 계정과 DB 접속 설정은 별도로 전달받은 값을 사용합니다.

## 실행

```bash
java -jar resource-manager-demo.jar
```

## 테스트

사용자·관리자 계정으로 로그인한 뒤 담당 기능을 확인합니다. 통합 흐름은 사용자 대여 신청 → 관리자 승인 → 사용자 반납 신청 → 관리자 반납 처리 → 이력·일정 확인 순서입니다.

각 담당자는 원본 PR과 현재 통합본을 비교해 정상 동작, 누락·변경된 기능, 재현 절차와 오류 내용을 보고합니다. 공유 DB의 기존 시연 데이터는 임의로 삭제하지 않습니다.
